# Fuentes visuales

La dirección visual toma referencias de layouts editoriales de interiorismo y e-commerce con fotografía dominante, mucho aire y navegación mínima.

Las imágenes de demo provienen de fuentes públicas externas (Pexels, Unsplash y sitios de fabricantes/referencias visuales). No se presentan como trabajos propios de Aberturas Avenida.

Antes de reutilización comercial permanente, conviene sustituir las imágenes externas por fotografías propias del local, productos y obras.
